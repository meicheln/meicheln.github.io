QCM Cyclohexane Sensor

Status
Designed + simulated
Parts
SN74LVC1GX04, 10 MHz AT-cut crystal, Arduino Due
Tools
EasyEDA Pro, Python (SciPy)

A Pierce oscillator drives a quartz crystal coated with a non-polar polymer. Cyclohexane vapour adds mass to the coating, and the frequency drops by a measurable amount.

  • Schematic passes design-rule check with 0 errors.
  • Wrote my own solver (negative-resistance + transient) because the simulator had no crystal model: it oscillates at 10.001410 MHz with a 22.8× start-up margin.
  • Mass sensitivity 0.2264 Hz per ng/cm², which matches the Sauerbrey equation.
  • Found the crystal drive at 213 µW, too high for a coated crystal. Changing R3 from 1 kΩ to 3.3 kΩ brings it to 93 µW and keeps an 11.9× margin.

StockSense

Status
Public, MIT
Stack
Python 3.12, Flask, SQLite, scikit-learn
Code
meicheln/stocksense ↗

A self-hosted scanner for the Indonesia Stock Exchange that reports how often it is wrong.

  • Screens 55 liquid IDX stocks with technical analysis, five separately audited ML models, foreign-flow tracking, paper trading and phone alerts. Installs on Android as a PWA.
  • Every number comes with the period it was measured on and a confidence interval.
  • A naive entry rule backtested over 10 years (3,572 trades) lost 96.3%. The app shows that result instead of hiding it.
  • Smoke tests guard against indicator look-ahead leakage and check IDX tick-size rounding.

Kontra

Status
Built, eval pending
Stack
React, Vite, TypeScript, Node, Claude API

A debate partner that attacks your argument instead of agreeing with it.

  • Opponent personas with adjustable intensity, a journal of past rounds, and a calibration view of how confident you were versus how you held up.
  • Runs on Claude when an API key is set, and on an offline template engine when it is not, so the whole flow works without a key.
  • A 50-claim evaluation set is written. It has not been run against the live model yet, so the quality targets are still targets.

Depot Air WA

Status
In setup
Stack
Node.js, Baileys (WhatsApp Web), Google Apps Script

An order book for a refill water depot. Customers order on WhatsApp and the app writes it down.

  • Messages like “3 galon” are parsed, recorded and confirmed with an automatic reply.
  • A local dashboard marks each order new, delivered or cancelled.
  • Orders sync to a Google Sheet daily report through an outbox that retries every minute, so nothing is lost while offline.

Trading Research Lab

Status

The tools I use to test a trading idea before trusting it with money.

  • SNIPER SMC, a TradingView indicator (liquidity sweep → displacement → order-block retest) with a per-signal win-rate table.
  • Python backtesters and MT5 Expert Advisors run headless in the strategy tester.

Method

Talent gets noticed. Systems get the work finished.

Measure before claiming

Simulate the oscillator before soldering. Backtest before trading. Put the test in the repo.

Publish the bad number

A −96% backtest or a drive level that is too high is useful information. It goes on the page.

Say what is not done

Each project states its status. “Simulated” is different from “built”, and I keep the two apart.
